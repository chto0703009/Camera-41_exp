# Camera-41_exp v0.1.1

Standalone MATLAB application for choosing the digital-camera shutter time for negative scanning, at a fixed selected aperture. Use empty film base + fog RAWs to compare signal and clipping margin across all four Bayer channels.

[English summary and installation (PDF)](https://github.com/chto0703009/Camera-41_exp/releases/download/v0.1.1/Camera41_exp_Summary_EN.pdf)

## Downloads and start

Download `Camera-41_exp-v0.1.1-macos.zip`, extract the complete folder and open **start.m** in MATLAB, then press **Run**. MATLAB is required. Read `INSTALL.md` and the included Swedish/English handbooks. The PDFs are also attached separately, together with one-page English and Swedish summaries. Verify downloads with `SHA256SUMS.txt`.

## Included

RAW previews and channel plots; automatic edge-safe area selection; yellow manual-review overlay when needed; measured time candidates; readable PASS/REVIEW/FAIL reports; remembered RAW folder; dialog focus restoration; full local diagnostic log; versioned bilingual handbooks; source code and licence notices.

## Verification and limits

MATLAB R2025b on macOS Apple Silicon: app/regression tests and an existing real RAW fixture analysed successfully. Bundled native readers unchanged from v0.1.0; physical Intel application use is unverified. Requires Image Processing Toolbox for ROI editing. Windows/Linux/older MATLAB releases are unverified.

Camera-41_exp is independent of PRE and NEG. It does not export a transfer JSON, change original RAWs, measure dark-pair noise or grant production qualification. If using PRE, capture the current film's FB+F and matched dark pair at the selected time and import those RAWs directly there.
